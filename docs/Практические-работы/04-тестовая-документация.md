# Практическая работа 4. Тестовая документация

Подготовьте короткий тест-план, чек-лист и кейсы выбранной области; оформите найденные ошибки с ожидаемым результатом из требования. Сохраняйте HTTP-коды, скриншоты, идентификаторы запросов и фрагменты логов. Проведите ревью баг-репорта из другой работы. Покрытие считайте по требованиям; количество тестов не равно покрытию.
