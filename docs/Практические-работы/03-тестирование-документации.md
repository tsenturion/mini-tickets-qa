# Практическая работа 3. Тестирование документации

Проанализируйте учебную копию требований ниже. Не используйте её как ожидаемое поведение приложения после ревью:

1. «Короткий заголовок допустим, максимальная длина разумная».
2. «Пользователь может удалить любую свою заявку; закрытые заявки неизменяемы».
3. «Пользователь видит свои заявки. По ссылке заявка доступна всем вошедшим».
4. «После ошибки входа показать понятное сообщение».

Оформите неоднозначность, противоречие или пропуск, задайте вопрос аналитику. После обсуждения используйте `ТРЕБОВАНИЯ.md` как согласованный контракт.
