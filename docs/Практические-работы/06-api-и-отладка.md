# Практическая работа 6. API и отладка

Импортируйте Postman-коллекцию и локальное окружение. Пройдите последовательность регистрации, входа, CRUD, комментариев и выхода. Изучите негативные запросы, заголовки, тело ошибки, отзыв токена. Добавьте не менее пяти собственных проверок.

В DevTools сопоставьте Network/Console с логами сервера по `X-Request-ID`. Напишите несколько API-проверок на Requests. Дополнительные упражнения по Basic Auth, OAuth и XML находятся в `labs/protocols.md`; основной вход стенда является Bearer-сессией, а не OAuth-сервером.
