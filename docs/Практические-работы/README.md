# Практические работы

Практические работы выполняются в отдельном репозитории тестов. Распределяйте области, допускайте пересечение проверок и проводите взаимное ревью результатов.

## Общие правила

Используйте только учебные учётные записи и собственную среду. Перед каждым прогоном сохраняйте версию продукта, адрес среды, исходные данные и идентификатор запуска. Разрабатывать приложение не требуется.

Каждая работа должна содержать API-, UI- и SQL-проверки там, где они применимы, а также краткое объяснение выбора проверок. Все требования и назначенные дефекты известны до оценивания. По умолчанию зачёт требует исправленных прогонов без ошибок и обнаружения не менее 75 % назначенных дефектов. Если заданию сопоставлены два дефекта, необходимо обнаружить оба.
