# Практическая работа 8. Автоматизация тестирования

Минимальный набор: пять API- и два UI-теста. Используйте фикстуры, уникальные данные, параметризацию и Page Object. Каждый тест свяжите маркером с реальным требованием. Запустите локально на исправленной версии, сохраните изменения в Git и отправьте PR/MR. Исправьте ложные падения и изучите, какие дефекты пропущены. Автопроверка не ставит баллы за ошибки импорта или тайм-аут подготовки среды.
