# Практическая работа 9. Проектная работа

Получите у преподавателя релиз-кандидат с закреплёнными коммитами шести вариантов и выбранным сочетанием ошибок. Проведите командой smoke, ретест, регрессию и полный прогон автотестов. На защите покажите один дефект с логами, объясните один пропущенный сценарий и обоснуйте решение о релизе с остаточными рисками. Новые функции продукта для этого этапа не требуются.
