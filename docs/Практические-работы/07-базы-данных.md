# Практическая работа 7. Базы данных

Выполните SQL-файлы 01–03 в личной БД. Проверьте сохранение POST через SELECT, сопоставьте автора комментария через JOIN, найдите пользователей и заявки без связанных записей. Изучите ошибку уникальности и FK, затем восстановите транзакцию через ROLLBACK. В микросервисной схеме выполните 04 и объясните отсутствие межбазовых FK.
