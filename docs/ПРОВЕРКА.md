## Дополнение: исправление запуска оценщика на Windows

Пользователь подготовил образ оценщика, но его прогон завершился infrastructure_error.
В сохранённых runner.log/infrastructure.log обнаружен Access is denied для bind mount
из системного Temp. В Python 3.13 каталог tempfile на Windows получает ограниченный
ACL; Docker Desktop не смог прочитать исходники и init-micro.sh.

Временные каталоги перенесены в игнорируемую .runtime/runs с наследуемыми разрешениями.
Глобальные ACL не менялись. Docker-коды 125/126/127 классифицируются как инфраструктурная
ошибка; при неуспешном эталоне дальнейшая матрица останавливается. Регрессия включает
проверки ACL-совместимого создания, целевой очистки, классификации и ранней остановки.

Полная контейнерная самопроверка `scripts/verify_grader.py --full` 9 сентября
завершилась с кодом 0: три fixed + повтор в обратном порядке прошли, 24 из 24
одиночных включений D01–D08 на трёх архитектурах обнаружены, оценка 100%.
Постоянно падающая и пустая работы дали invalid_submission, как и предусмотрено.
Итоги находятся в artifacts/grader-self-test/{reference,always-fails,empty}/grade.json.
Оценщик проверен на коммите 42ea9ec270cd46ff101ec06cbe028d8fc4425973;
продуктовые SHA — неизменённый манифест releases/1.0.0.json.

Дополнительно исправлена очистка read-only объектов временных Git-репозиториев
в Windows: атрибут снимается только с собственного проверенного временного файла,
прочие отказы не скрываются. Это подтверждено модульным тестом с настоящим Git-коммитом
и успешным завершением полной контейнерной репетиции. Большой образ уже скачан;
повторная сборка использует кеш.

## Что оставлено запущенным

На этой машине порт 8000 занят другим проектом Docker. В локальном игнорируемом
`.env` задан LAB_PORT=8001: учебная среда доступна на http://localhost:8001,
PostgreSQL — localhost:55432. После клонирования без этого локального файла
применяется стандартный порт 8000. Чужие контейнеры не останавливались.
Учебные логины и команды остановки — в README. Данные основной среды сохранены.
Временные проверочные среды удаляются после экспорта логов. Данные удалённого
доступа, приватные ключи и токены не добавлялись в репозиторий.
