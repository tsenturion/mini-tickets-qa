# Учебный выпуск 1.0.0

Выпуск фиксирует шесть самостоятельных вариантов минимального приложения «Мини‑заявки». Он предназначен для ручного тестирования, API- и SQL-проверок, автоматизации на Playwright/Pytest и запуска CI.

## Состав

- `1.0.0.json` — манифест с точными SHA-коммитами шести вариантов;
- шесть ZIP-архивов — исходный код каждого варианта из манифеста;
- `SHA256SUMS.txt` — контрольные суммы JSON-файла и всех ZIP-архивов;
- автоматически сформированные GitHub архивы исходного кода тега.

Каждая архитектура представлена в состояниях `fixed` и `buggy`: `monolith`, `client-server`, `microservices`. Вариант `buggy` содержит намеренно внесённые дефекты для практических заданий, а `fixed` — эталонное исправленное состояние.

## Проверка целостности

После загрузки файлов выполните в PowerShell из каталога с артефактами:

```powershell
Get-FileHash .\* -Algorithm SHA256
```

Сверьте значения для JSON и ZIP с `SHA256SUMS.txt`. Для локальной проверки манифеста в клоне проекта:

```powershell
.\.venv\Scripts\python.exe scripts\validate_release.py --version 1.0.0
```

Полный порядок подготовки окружения, запуска приложения и проверок приведён в основном README.
